# 病史随访追踪系统

## 轻量入口

当用户提供病历图片/文字文件夹，并希望整理为结构化笔记时使用本 Skill。

## 何时使用

- 用户发来微信截图、化验单照片、就医文字描述等零散病历资料
- 用户说"帮我整理病历""把这些转成笔记""建一个病史随访档案"
- 用户希望有清晰的时间轴、用药追踪、化验指标对比
- 用户需要增量更新（新增资料后追加，不重头来过）
- 用户需要导出为 HTML 发给朋友，或打印 PDF

## 工作流总览

```
📥 输入（零散资料）
  ├── *.txt          文字描述（事件说明）
  ├── *.jpg/*.png    微信截图、化验单照片
  └── 按年份分目录    2025年事件/ 2026年事件/

        ↓  [Step 1] OCR 文字提取 (easyocr)

📊 结构化数据
  ├── OCR 文本缓存
  └── JSON 增量缓存（记录已处理文件）

        ↓  [Step 2] AI 整理 → 结构化笔记

📝 Obsidian 笔记（5个）
  ├── {姓名}_主档案.md        ← 基本信息、诊断、摘要
  ├── {姓名}_时间轴.md        ← 按日期的时间线（兼容1st-Timeline）
  ├── {姓名}_用药记录.md      ← 用药变更 + 注意事项
  ├── {姓名}_化验指标追踪.md  ← 按类别纵向追踪表
  └── {姓名}_咨询问题.md      ← 待问问题分级清单

        ↓  [Step 3] 合并

📋 {姓名}_完整病历.md         ← 合并文档（文字+图片附件引用）
📁 附件/                     ← 原始图片

        ↓  [Step 4] 导出

🌐 {姓名}_完整病历.html      ← 单文件，左侧目录 + 图片内嵌
🖨️ 浏览器 Ctrl+P → PDF      ← 一键打印
```

## 执行流程（Claude Code 自动执行）

### Phase 1: 环境准备

1. 确认 Python 3.10+ 和依赖已安装
2. 确认输入目录结构（`年份/` 子目录 + txt + 图片）
3. 确认输出目录（Obsidian vault 路径）

### Phase 2: OCR 提取

1. 对每个子目录运行 OCR
2. 生成 `{图片名}.md` 存放 OCR 文本
3. 生成 `{年份}_图片汇总.md` 合并该年所有图片文字
4. 保存增量缓存，标记已处理文件

### Phase 3: AI 整理笔记

Claude 根据 OCR 文本自动：

1. **提取关键信息**：日期、医院、科室、医生、诊断、化验项目及结果
2. **识别异常指标**：标注 🔴（异常）/ 🟡（关注）/ ✅（正常）
3. **生成5个笔记**：
   - 主档案：患者信息 + 病史摘要 + 异常追踪 + 当前用药
   - 时间轴：每个就诊节点含完整化验表格 + Callout 标注
   - 用药记录：用药变更时间轴 + 注意事项（抗凝药/降压药/降糖药等）
   - 化验追踪：按 血常规/生化/免疫/凝血/影像 等分表
   - 咨询问题：紧急/近期/长期三级

### Phase 4: 生成合并病历

1. 创建 `{姓名}_完整病历.md`，按章节（病史背景 → 逐年事件 → 当前状态 → 指标追踪 → 问题建议）
2. 每个时间节点：文字说明 + `![[附件/原始图片名]]` 引用
3. 复制原始图片到 `附件/` 目录
4. 关联所有子笔记 `[[链接]]`

### Phase 5: 导出 HTML

1. 图片 base64 内嵌
2. 左侧固定目录导航（52+ 锚点）
3. 移动端折叠目录 + 红色浮动按钮
4. 右上角「导出PDF」按钮（触发浏览器打印）
5. 打印样式：自动隐藏目录/按钮，只留正文

### Phase 6: 增量更新

当用户提供新资料时：
1. 扫描输入目录，对比缓存
2. 只处理新文件（OCR + 标记）
3. 追加到已有笔记（不覆盖）
4. 重新生成合并 MD 和 HTML

## 技术细节

### 依赖

```
easyocr>=1.7.0    # OCR 文字识别（中文+英文）
numpy>=1.24.0     # 图像数据处理
Pillow>=10.0.0    # 图片读取（绕过 OpenCV 中文路径问题）
PyYAML>=6.0       # 配置文件解析
```

### 文件格式约定

- **输入格式**：`{年份}年事件/{年份}年事件.txt` 包含事件描述
- **图片命名**：任意，按文件名排序即按时间排序
- **输出格式**：Obsidian 兼容 Markdown + YAML frontmatter + Wiki 链接
- **缓存文件**：`.medical_tracker_cache.json`（记录已处理文件 + 结构化数据）

### 兼容的 Obsidian 插件

| 插件 | 用途 |
|------|------|
| [1st-Timeline](https://github.com/lnabc03/1st-Timeline) | 时间轴可视化 |
| [Dataview](https://github.com/blacksmithgu/obsidian-dataview) | 跨笔记数据查询 |
| [Mermaid](https://mermaid.js.org/) | 时间线图渲染（Obsidian 原生） |

### 错误处理

- OpenCV 中文路径问题 → 用 PIL 读取图片
- GBK 编码问题 → 所有 I/O 用 UTF-8
- OCR 识别乱码 → 标注"[OCR 失败]"并保留原始图片
