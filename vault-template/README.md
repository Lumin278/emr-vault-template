# 病历管理 · 电子病历库

> **中文名：病历管理**（也叫 电子病历库 / 健康档案库）｜由 AI Agent 维护
>
> 本库是"全量记忆 + 备份"的载体：agent 归档的资料落在这里，其他设备取回副本用于查看与备份。
> **归档规矩见 `AGENTS.md`；项目名必须取自 `8-知识库/项目名规范.md`。**

## 结构：库 → 人 → 档案

```
电子病历库/                        ← Obsidian 打开的就是这一层（库根）
├── AGENTS.md  README.md  IDEA.md
├── 8-知识库/                      ← 全库共享：项目名规范、设计说明、选型与参考项目、用药指南
├── 9-模板/                        ← 全库共享：归档模板
│
└── 张三/                          ← 点名字进去 = 这个人的全部档案
    ├── 1-基本信息/
    ├── 2-检查报告/
    ├── 3-不适记录/
    ├── 4-就医记录/
    ├── 5-指标/
    ├── 6-用药/
    ├── 7-视图/
    ├── 8-体重管理/                （自己测的体重/体成分长表，不进 5-指标）
    └── attachments/               （待归类原图暂存，不编号）
```

**加人**：库根 `mkdir <名字>/`，按上面建子目录（`8-知识库/`、`9-模板/` 不复制）。
**当前成员**：张三。

> **同号不同层**：成员目录里的 `8-体重管理/`（成员级）与库根的 `8-知识库/`（库级共享）同号但不冲突 —— 引用时带路径。

## 成员目录里的子目录（编号 = 阅读顺序）

| 目录 | 放什么 |
|---|---|
| `1-基本信息/` | 姓名、过敏史、慢病、紧急联系人（**完整版含隐私，只在本库**；**不存用药**，用药见 `6-用药/`）。**本页是基准线**：默认只读，除本人主动要求不改、不主动问 |
| `2-检查报告/` | **一次检查活动一个目录**：`YYYY-MM-DD-机构-活动/`，内含汇总页 + `报告/` + `attachments/`（原图） |
| `3-不适记录/` | `不适记录.md` —— 自述不适的**纯记录**（没看病也记）：日期 / 不适的感受 / 我怎么处理的 / 持续多久 |
| `4-就医记录/` | **就医记录总表**（一行一次医疗接触；年子表自动生成）——症状/结论/**用药快照**/医嘱/复查/检查报告 |
| `5-指标/` | `指标总表.csv` —— 跨来源的**数值**长表（只装有检验报告的临床数值），用于趋势与对比 |
| `6-用药/` | `用药流水.md` —— 按「药」为主线：长期服用 / 医嘱用药 / 自我用药（含停止原因） |
| `7-视图/` | 给医生看的三件套：主档案 / 用药记录 / 化验指标追踪 |
| `8-体重管理/` | `体重管理总表.csv` —— **自己测的**体重 / 体成分长表（一次测量 = 一组行）。**不进** `5-指标`；**不留截图原图**，只提取文字 |

## 五条主线

| 视角 | 载体 | 回答 |
|---|---|---|
| **感受** | `3-不适记录/不适记录.md` | 我什么时候有过什么不舒服？这次是不是老毛病、之前有没有过？ |
| **事件** | `4-就医记录/总表` + `2-检查报告/活动目录` | 我什么时候看了什么病、结果如何、用了什么药、原件在哪 |
| **药物** | `6-用药/用药流水.md` | 这个药吃了多久、调过几次、为什么停 |
| **数值** | `5-指标/指标总表.csv` | 某个指标这几年的走势 |
| **体态** | `8-体重管理/体重管理总表.csv` | 体重 / 体成分怎么变的（画曲线用） |

## 主要产出

- **面向医生的病历报告（PDF）**：三件套 + 本次症状（可从 `3-不适记录` 抽时间线）+ 指标时间对比，**脱敏后**输出
- **换设备时的备份副本**：整个库打包（git 版本化，可回溯）
