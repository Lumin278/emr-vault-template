# 电子病历库

把家庭成员的体检报告、化验单、处方与就医记录，归档成一套可检索、可追溯、可带走的 Obsidian 电子病历库。

**结构：库 → 人 → 档案。** 打开库看到的是成员名字；点进名字，才是这个人的档案目录（1-基本信息 / 2-检查报告 / 3-不适记录 / 4-就医记录 / 5-指标 / 6-用药 / 7-视图 / 8-体重管理）。

- 数据入口：在会话里上传的单子照片 / 文字，由 agent 读图抽取
- 归档产物：结构化笔记（frontmatter 规范字段）+ 原图副本 + 指标 CSV + 按人视图
- 药名统一走标准名（通用名＋剂型），副作用/禁忌/相互作用查药品说明书库（库外，数据自备）
- 边界：只做整理与引用 —— 不诊断、不给用药建议、不判断紧急度
- 备份：库内 git 快照；需要时打包到其他设备存副本
- 面向医生的输出：**面向医生的病历报告（脱敏 PDF）** = 主档案 + 用药记录 + 化验指标追踪 + 本次症状

> 编辑自由：这是给你自己看的说明，随时改。归档的具体规矩在 `AGENTS.md` 与 `health-vault` 技能里。
