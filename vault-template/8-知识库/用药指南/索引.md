# 用药指南（索引）

> 这个目录放**药品说明书数据**与查询说明。**本仓库不附带任何药品数据**（体积 + 版权原因）。

## 为什么推荐做成"可查询的库"而不是一堆 Markdown

一份完整的中文药品说明书库有上万条，每条数千字。塞成 Markdown 文件既难读也难查。
更好的做法：**把它做成一个本地数据库（SQLite）+ 一个查询脚本**，只在需要时取命中行 —— 既省上下文，也快。

## 推荐的数据源

| 来源 | 说明 |
|---|---|
| **RxNorm / RxNav**（美国 NLM） | 有明确授权，REST API 免认证，给药名归一与相互作用 |
| **openFDA 药品标签** | 含 `drug_interactions` / `adverse_reactions`，可批量拉取 |
| 自行整理的中文说明书数据 | 注意：公开可得的整理集**多有版权问题，仅供个人参考，不要再分发** |

本仓库 `tools/` 里的 `build.py`（建库）与 `q.py`（查询）可以直接用，只要按脚本里的表结构把数据喂进去。

## 归档里的用法（与药名规范配合）

- 药名统一写 **通用名（剂型）**，如 `布洛芬（缓释胶囊）`
- 用户报商品名（如"芬必得"）→ 查库对照 → **回问确认** → 落通用名
- 边界：只照录说明书原文，**不做任何用药判断或建议**
