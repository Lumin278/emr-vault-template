# 项目名规范（受控词表）

> **为什么有这份文件**：报告项目名必须唯一、稳定，否则以后"导出近 10 次心电图""挖近 10 次血常规的变动"这类检索会漏、会重。
> **本文件是那份"地基"**：任何项目名只能取自这里；遇到词表里没有的，**先问用户**，再补进来（连同别名一起登记）。
> 规矩变更**写在仓库里**，不依赖 agent 的记忆（记忆会被压缩、磨损）。

---

## 规则

1. **只用标准名**，不得同义异写（"心电图 / ECG / 心电检查" 只保留 **心电图**）
2. **新项目流程**：先问用户 → 定标准名 → 在对应表里加一行 → 把见过的别名写进"别名"列
3. 标准名要**短、中文、无空格**；同类变体用后缀区分（心电图 / 动态心电图）
4. 文件名：报告页 `<标准名>-YYYY-MM-DD.md`；原图 `YYYY-MM-DD_<标准名>_原图[_pN].ext`
5. 分不清、用户也说不清时 → **停下来问**，不要自己发明一个名字

## 四、指标名（化验细项 → 进 `指标总表.csv` 的「指标名」列）

同一指标只能有一种写法，括号里是允许的补充说明。

**肝功**：ALT(丙氨酸氨基转移酶)、AST、GGT、ALP、TBIL(总胆红素)、DBIL、IBIL、TP、ALB、GLB
**肾功**：BUN(尿素)、Cr(肌酐)、UA(尿酸)、eGFR
**血糖血脂**：GLU(空腹血糖)、HbA1c、TC(总胆固醇)、TG(甘油三酯)、HDL-C、LDL-C
**血常规**：WBC、RBC、Hb(血红蛋白)、PLT、NEUT%(中性粒细胞%)、LYMPH%、MONO%、EO%
**甲功**：TSH、FT3、FT4、TT3、TT4、TPOAb、TgAb
**凝血**：PT、INR、APTT、FIB、D-二聚体
**其他**：CRP、ESR(血沉)、维生素D、铁蛋白
**体征**（手测/体检测得，也进表）：收缩压、舒张压、心率、体温、身高、体重、BMI

> **补充方式**：发现词表里没有的项目或指标 → **先问用户** → 确认标准名 → 加进本表（含别名）。
> 这份表是"以后能不能一键把近 N 次某项目捞出来"的前提。
