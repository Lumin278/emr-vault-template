# 项目名规范（受控词表）

> **为什么有这份文件**：报告项目名必须唯一、稳定，否则以后"导出近 10 次心电图""挖近 10 次血常规的变动"这类检索会漏、会重。
> **本文件是那份"地基"**：任何项目名只能取自这里；遇到词表里没有的，**先问用户**，再补进来（连同别名一起登记）。
> 规矩变更**写在仓库里**，不依赖 agent 的记忆（记忆会被压缩、磨损）。

---

## 规则

1. **只用标准名**，不得同义异写（"心电图 / ECG / 心电检查" 只保留 **心电图**）
2. **新项目流程**：先问用户 → 定标准名 → 在对应表里加一行 → 把见过的别名写进"别名"列
3. 标准名要**短、中文、无空格**；同类变体用后缀区分（心电图 / 动态心电图）
4. 文件名：报告页 `<标准名>-YYYY-MM-DD.md`；原图 `YYYY-MM-DD_<标准名>_原图[_pN].ext`；**一张单据含多个检查项目时，原图项目名用 `+` 连接**（如 `电解质+肾功`），各报告页共用该原图。一份报告跨多页时，页码写在名字末尾（`_p1`/`_p2`…，按该单据的页序）。**不是检查项目的页**（封面、检查项目清单、总检报告等）按页名命名：`YYYY-MM-DD_<页名>_原图.ext`（如 `2020-11-30_总检报告_原图.jpg`）。**同一张照片上既有检查项目、又有门诊病历 / 处方时**，按检查项目命名（页名不写），并在汇总页注明该照片另含门诊病历 / 处方
5. 分不清、用户也说不清时 → **停下来问**，不要自己发明一个名字

## 四、指标名（化验细项 → 进 `指标总表.csv` 的「指标名」列）

同一指标只能有一种写法，括号里是允许的补充说明。

**肝功**：ALT(丙氨酸氨基转移酶)、AST、AST/ALT（比值）、GGT、ALP、TBIL(总胆红素)、DBIL、IBIL、TP、ALB、GLB、前白蛋白(PA)、总胆汁酸(TBA)、白球比(A/G)
**肾功**：BUN(尿素)、Cr(肌酐)、UA(尿酸)、eGFR
**血糖血脂**：GLU(空腹血糖)、HbA1c、TC(总胆固醇)、TG(甘油三酯)、HDL-C、LDL-C
**尿常规**：尿比重、尿酸碱度
**电解质**：钾(K)、钠(Na)、氯(Cl)、钙(Ca)
**血常规**：WBC、RBC、Hb(血红蛋白)、PLT、NEUT%(中性粒细胞%)、LYMPH%、MONO%、EO%、嗜碱性粒细胞百分比(BASO%)、中性粒细胞绝对值(NEUT#)、淋巴细胞绝对值(LYMPH#)、单核细胞绝对值(MONO#)、嗜酸性粒细胞绝对值(EO#)、嗜碱性粒细胞绝对值(BASO#)、红细胞压积(HCT)、平均红细胞体积(MCV)、平均红细胞血红蛋白含量(MCH)、平均红细胞血红蛋白浓度(MCHC)、红细胞体积分布宽度(RDW SD)、红细胞体积分布宽度(RDW CV)、平均血小板体积(MPV)、血小板体积分布宽度(PDW)、血小板压积(PCT)、大血小板比率(P-LCR)、幼稚粒细胞绝对值(IG#)、幼稚粒细胞百分比(IG%)、有核红细胞绝对值(NRBC#)、有核红细胞百分比(NRBC%)（医院 App 单据常写作「白细胞计数(WBC)」「血红蛋白量(HGB)」「红细胞比积(HCT)」「RDW-SD / RDW-CV」等：录入时按上面的写法，不另立新名）
**甲功**：TSH、FT3、FT4、TT3、TT4、TPOAb、TgAb
**凝血**：PT、INR、APTT、FIB、D-二聚体
**其他**：CRP、超敏C反应蛋白(hs-CRP)、ESR(血沉)、维生素D、铁蛋白
**体征**（手测/体检测得，也进表）：收缩压、舒张压、心率、体温、身高 —— **体重、BMI 不在此**：自测的体重/BMI 一律记 `<成员>/8-体重管理/体重管理总表.csv`（见「六、体重管理类」）

> **补充方式**：发现词表里没有的项目或指标 → **先问用户** → 确认标准名 → 加进本表（含别名）。
> 这份表是"以后能不能一键把近 N 次某项目捞出来"的前提。

## 五、机构名（「机构 / 医生」列与检查活动目录名）

同一家医院**只保留一种写法**：

| 标准写法 | 单据上见过的其他写法 |
|---|---|
| 〈医院全称，如 XX 市人民医院〉 | 〈简称，如 XX 人民医院 / XX 医院〉 |

- **标准写法取单据全称**：同一家医院在不同单据上可能印全称与简称 → 确认为同一家后**统一写全称**。
- 历史检查活动目录名**只增不改**保留原名；要统一改名时先问用户。
