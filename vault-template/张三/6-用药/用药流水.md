# 用药流水

> **以「药」为主线**的记录（就医记录表按事件排，这里按药排）。
> 三类来源都在这里：
> - **(a) 长期服用 / 保健品** → 见下面「当前在服」表（含复合维生素、品牌）
> - **(b) 看病开的药**：医生开了什么、我实际怎么吃、吃了多久 → 见「按药分节」
> - **(c) 自我用药**：自己不舒服时吃什么、吃多久、**为什么停** → 见「按药分节」（`依据 = 自主`）
>
> 药名统一写 **通用名（剂型）**；**剂量你补充了我就记，没补充就留空**。
> 就医记录总表的「用药 / 治疗」列写**本次就诊的快照**（这次开了什么）—— 与本文件**有意交叉**：那里看"这一次用什么"，这里看"这个药吃了多久、为什么停"。**两处都要写**，只更新一处算待核对。
