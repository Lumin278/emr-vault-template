# 6-用药 — 怎么用

## 只有一个主文件

**`用药流水.md`** —— 按「药」为主线，覆盖三类来源：

| 来源 | 记在哪 | 依据字段 |
|---|---|---|
| (a) 长期服用 / 保健品（复合维生素、品牌等） | 顶部「当前在服 / 长期服用」表 | `医嘱` 或 `自主` |
| (b) 看病开的药：开了什么、实际怎么吃、吃多久 | 下面「按药分节」的时间线 | `医嘱` |
| (c) 自我用药：自己不舒服吃什么、吃多久、为什么停 | 同上，`停止原因` 必填 | `自主` |

## 字段约定

- **药名**：统一 `通用名（剂型）`，如 `布洛芬（缓释胶囊）`、`左甲状腺素钠（片）`
  - 你报商品名（优甲乐 / 芬必得）→ 我查药品库 → **反问你确认** → 落库用通用名
- **剂量**：你说了就记（`50μg qd`、`0.5g tid ×3天`）；没说就留空，**不猜**
- **动作**：开始 / 调量 / 续方 / 停
- **依据**：`医嘱` 或 `自主`（这条能区分"医生让吃"和"我自己吃"）
- **停止原因**：症状好了 / 医生让停 / 副作用 / 换药 / 忘了（照你说，不美化）
- **来源**：链到 `[[就医记录总表]]` 或写「自述」

## 与其他目录的关系

- **就医记录总表的「用药 / 治疗」列 = 本次快照**（这次开了什么药、做了什么处置）→ 与本文件**有意交叉**：那列看"这一次用什么"，本文件看"这个药吃了多久、为什么停"。两处都要写，只更新一处算待核对
- `7-视图/用药记录.md` = **给医生看的用药汇总**（从本文件派生，不要单独维护）
- `8-知识库/用药指南/` = 药品说明书库（副作用 / 禁忌 / 相互作用），直接问我即可
- 处方原始单据（病历本、处方笺照片）放对应 `2-检查报告/<活动>/attachments/`

## 边界

❌ 不判断该不该吃、要不要停、换什么药、症状是不是这药引起的 —— 只记录、只照录说明书原文。
