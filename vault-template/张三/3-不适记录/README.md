# 3-不适记录 — 怎么用

## 这是什么

**纯记录**：日常不舒服就记一句，**没看病也记**。用途只有一个 —— 以后真发病了，回来**溯源**："之前有没有过这种不适？"

就四列：**日期 · 不适的感受 · 我怎么处理的 · 持续多久**。

## 怎么用

**不用打卡、不用整理**。哪天真觉得不舒服，在会话里说一句："这两天左太阳穴一跳一跳地疼，熬夜之后更明显，没管它，睡了就好"。agent 追加一行，照你的原话。

**回查**：直接问「我以前有没有头疼过」「上次胃不舒服是什么时候」→ agent 按时间把这几年同类条目列出来。

## 和「自查」的区别

| | 3-不适记录 | 4-就医记录 的 `类型: 自查` |
|---|---|---|
| 发生了什么 | 只是**有不舒服**（可能无视、可能就记一下）| **自己判断 + 自己吃药处理了** |
| 算不算一次医疗接触 | 不算 | **算**（所以进就医记录总表）|

两条不冲突：先有不适记录 → 后来自己吃药了 → 那就再补一条 `自查`；后来去医院了 → 补一条正常就医记录。

## 吃了药怎么办

「我怎么处理的」列照写（如"吃了片布洛芬"），我同时在 `6-用药/用药流水.md` 补一条（`依据: 自主`），这样药的历史不会断。

## 边界

❌ 不诊断、不猜病因、不做可能性排序、不判断紧急度、不给用药建议。
✅ 只做两件事：**照原话记录** + **按时间检索**。
