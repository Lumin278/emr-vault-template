# 8-体重管理 — 怎么用

## 这是什么

**自己测的**体态数据（体重 / 体成分）。它和 `5-指标/指标总表.csv` **刻意分开**：

| | `5-指标/指标总表.csv` | `8-体重管理/体重管理总表.csv` |
|---|---|---|
| 数据从哪来 | **有检验报告**的临床数值 | **自己在家测的**（体脂秤 / 身体成分）|
| 有没有参考范围 | 有（单据上印的）| App 只给"标准 / 偏高 / 偏低"这类标签 |
| 频率 | 一年几次 | 可能一天几次 |
| 用途 | 给医生看（报告从它派生）| 自己看曲线 |

混在一起的话，"异常"那一列会失去意义，而且"近 N 次血常规"这种检索会被高频体重行淹没。

## 文件

`体重管理总表.csv` —— 唯一数据源，**长表**：**一次测量 = 一组行，一行一个指标**。

```
日期,时间,患者,来源类型,项目,机构/设备,指标名,值,单位,参考范围,判定,笔记
```

- `来源类型`：**自测**（家用设备）／体检／就诊 —— 「自测」是本目录专有值
- `项目`：词表标准名（当前是 `体脂秤`）；`指标名` 取自 `8-知识库/项目名规范.md` 的「体重管理指标名」
- `单位` / `参考范围`：**设备上印了才写**；App 只给定性标签时留空
- `判定`：**照抄 App 的标签**（标准 / 偏高 / 过高 / 偏低），不自己判读、不换算
- 同一天多次称重：**逐条追加，不合并、不取平均**；设备没给的项**不写行**

## 怎么用

**不用打卡**。把体脂秤 App 的结果截图发进会话（或者说一句数字），agent 追加一组行、只提取文字。

**不留原图** —— 截图不复制进库（复查看表即可，存图没意义）。

**不看医生**：这不是一次医疗接触 → **不建检查活动、不加就医记录、不进 `5-指标`**。

**回查**：直接问「我最近体重怎么变的」「上个月体脂多少」→ agent 按日期把行列出来 / 画曲线。
