# 就医记录 · 总表

> 从最早到现在的**全部就医记录**，一行一次医疗接触（含"自查"）。
> **本表是唯一手写源**：年子表（`2021.md` 等）由 agent 按本表自动生成，不要直接改子表。

**列说明**：`医生` 并进「机构 / 医生」列（如 `协和·张医生`）；「判断 / 结论」写**一句话摘要**，完整结论在检查活动页；`自查` 行的「医嘱 / 检查报告」留空；`ID` 列给机器配对用（检查活动页 frontmatter 写同一个 `就医ID`），你可以不看。

**同一次看病的多张单子（检查日期落在 7 天内）**：先确认是不是同一次 → 是的话**本表只加一行**（日期取**最早那天**），检查报告合并为**一个活动目录**；各单据自己的日期照抄不改。

| 列 | 填什么 |
|---|---|
| 日期 | `YYYY-MM-DD`；住院跨天用 `YYYY-MM-DD~MM-DD` |
| 机构 / 医生 | `协和·张医生`；自查写 `—` |
| 类型 | `体检` / `就诊` / `住院` / `复查` / `自查` |
| 科室 | 无则留空 |
| 症状 / 主诉 | 当时什么不舒服、多久了（**为什么去**） |
| 判断 / 结论 | 医生诊断原话的**一句话摘要**；自查写 `自主判断：xxx` |
| **用药 / 治疗** | 这次**开了什么药、用了什么药**（快照，如 `阿莫西林 0.5g tid ×3天`）。**与 `6-用药/用药流水.md` 有意交叉**：这里看"这一次开了什么"，流水看"这个药吃了多久、为什么停"。非药物处置（输液/打针/雾化/换药/理疗）也写这里 |
| 医嘱 | 医生交代的注意事项 |
| 下次复查 | 结构化日期（便于提醒）；没有留空 |
| 检查报告 | `[[检查活动]]` 链接；没做检查留空 |
| ID | `YYYYMMDD+序号`，如 `20260911a` |
