# 4-就医记录 — 怎么用

## 两张表，结构相同

| 文件 | 内容 |
|---|---|
| `就医记录总表.md` | 从最早到现在的**全部**记录（按年份分小节） |
| `2021.md` / `2022.md` … | **年子表**：把总表按年份拆出来，结构与总表相同 |

**总表是唯一手写源，年子表由 agent 自动生成**（每次归档后重生成对应年份）。你只改总表，或在会话里让我改。

## 一行 = 一次医疗接触

| 列 | 填什么 |
|---|---|
| 日期 | `YYYY-MM-DD`；住院跨天用 `YYYY-MM-DD~MM-DD` |
| 机构 / 医生 | `协和·张医生`；自查写 `—` |
| 类型 | `体检` / `就诊` / `住院` / `复查` / `自查` |
| 科室 | 无则留空 |
| **症状 / 主诉** | 当时什么不舒服、持续多久（**为什么去**）；自查尤其要写 |
| **判断 / 结论** | 医生诊断原话的**一句话摘要**；自查写 `自主判断：xxx` |
| **用药 / 治疗** | 这次**开了什么药、用了什么药**（快照）。非药物处置（输液/打针/雾化/换药/理疗）也写这里 |
| 医嘱 | 医生交代的注意事项、复查要求 |
| 下次复查 | 结构化日期（便于以后提醒）；没有留空 |
| 检查报告 | `[[检查活动]]` 链接；没做检查留空 |
| ID | 机器配对用（`20260911a`），你不用管 |

## 「用药 / 治疗」列与用药流水的关系（有意交叉）

| 想知道 | 去哪看 |
|---|---|
| **这一次**看病开了什么药 | 本表这一行的「用药 / 治疗」列（**一眼看到，不用点链接**）|
| 这个药**吃了多久**、调过几次量、为什么停 | `6-用药/用药流水.md` 的对应药那一节 |
| 我**现在**在吃什么 | `6-用药/用药流水.md` 顶部「当前在服」表 |

两处**故意重复**：本表是"事件快照"，流水是"药物一生"。归档时两处一起写；如果只更新了一处，属于待核对项。

## 与其他目录的关系

- **明细与原图** → `2-检查报告/<活动目录>/`（「检查报告」列链过去）
- **用药的完整过程** → `6-用药/用药流水.md`（列里只放快照）
- **数值** → `5-指标/指标总表.csv`（本表不记数值）
- **给医生看的汇总** → `7-视图/`（主档案 / 用药记录 / 化验指标追踪）

## 关于行级链接

Markdown 表格的一行**不能**挂块 ID（`^id`），所以用 **`ID` 列 + 检查活动页 frontmatter 的 `就医ID`** 双向配对：从检查报告能跳回本表，我也能用 ID 校验有没有漏链。
