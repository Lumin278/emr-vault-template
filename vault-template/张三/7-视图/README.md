# 7-视图 — 给医生看的三件套

这里是**跨事件累积的汇总视图**，也是生成「面向医生的病历报告」的素材来源。
（早期还有「时间轴」与「咨询问题」两个视图，后来按"对医生没用"删掉了。）

## 三件套（也是报告的三个部分）

| 文件 | 给医生看什么 | 数据来源 |
|---|---|---|
| **主档案.md** | 基本信息 + 病史摘要 + 关键异常指标 + 当前用药 | `1-基本信息/` + 各记录汇总 |
| **用药记录.md** | 最近几次用药（现在在吃什么、吃过什么、吃多久） | `6-用药/用药流水.md` 派生 |
| **化验指标追踪.md** | 相关化验指标的分组纵向对比（带时间） | `5-指标/指标总表.csv` 派生 |

## 命名

- **单人**：三个文件直接用上面的名字
- **多人**：`主档案-妈妈.md`、`化验指标追踪-妈妈.md` …（成员名与 `1-基本信息/`、指标总表的 `患者` 列保持一致）

## 生成方式

- **不要手工维护**：`用药记录.md` 和 `化验指标追踪.md` 由 agent 从上游数据派生（总表 / CSV），改了上游说一声我重生成
- `主档案.md` 是半手工的：基本信息与病史摘要由 agent 维护，你可以直接在 Obsidian 里补

## 与报告的关系

`面向医生的病历报告` = 三件套 + 本次症状描述 + 指标时间对比（标上涨/下降）+ 脱敏处理 → **输出 PDF**。
流程与脱敏规则见 `AGENTS.md`。
